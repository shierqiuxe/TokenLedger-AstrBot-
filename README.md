# TokenLedger

> AstrBot 官网：[astrbot.app](https://astrbot.app)　·　本插件仓库：[shierqiuxe/TokenLedger-AstrBot-](https://github.com/shierqiuxe/TokenLedger-AstrBot-)

给 AstrBot 装一个账本，记下**每一次对话到底花了多少 token**。

平时这些数字一闪就没了，钱却实打实在走。装了这个插件，每聊一句就悄悄记一笔：
谁说的、在哪个群、用的哪个模型、输入多少、缓存命中多少、输出多少。
今天花了多少、这周比上周多花了几成、哪个群是话痨、哪个模型最烧钱——面板里点开就能看。

> 数据全程留在你机器上，不联网、不发送、不碰聊天内容。

---

## 一、它长什么样

面板侧栏「扩展功能」里会多出一个 **TokenLedger**，点开是这样的：

| 区域 | 内容 |
| --- | --- |
| 四张卡 | 今天 / 本周 / 本月 / 全部，各自带**环比涨跌**（比昨天、比上周、比上月） |
| 最近 14 天 | 堆叠柱状图，一根柱子分三段：正常输入 / 缓存命中 / 输出。鼠标停上去看当天明细 |
| 谁最费 | 排行榜，可以切「模型 / 会话 / 用户」三种口径 |
| 逐条流水 | 每一笔账一行：时间、谁、**发起**、模型、入、缓存、出、合计 |

「发起」这一列说的是**这轮对话谁先开的口**：青色的 <kbd>它</kbd> 是机器人自己找上来的，灰的 <kbd>你</kbd> 是人先去问它的，破折号是这笔账看不出是谁起的头（老账、或者没记全）。四张卡的标题右边也会写「它先开口 N」，一眼就能知道今天有几次是它主动的。

页面每 30 秒自己刷一遍，右上角还能手动刷。
「记账中」这个小绿点亮着，说明钩子挂上了、正在收账；变成黄的说明还没收到过回复。

## 二、安装

### 方式一：面板上传（推荐）

1. 把 `TokenLedger-v1.1.1.zip` **整个**上传到 AstrBot 面板的「插件管理 → 安装插件」。
   > zip 里面已经包了一层同名文件夹，直接传，不用自己解压再压。
2. 装完在插件卡片上点「启用」。
3. 侧栏「扩展功能」里就会出现 **TokenLedger**。

### 方式二：手动放

把 `astrbot_plugin_token_meter` 文件夹整个放进 `AstrBot/data/plugins/`，重启 AstrBot。

### 装完看一眼

侧栏「扩展功能」里点 **TokenLedger**，能打开就是通了。用一阵子再回来，卡片上应该开始有数。

## 三、指令

不想开面板，在群里直接问也行：

| 指令 | 干啥 |
| --- | --- |
| `/用量` | 今天和这周花了多少 |
| `/用量 昨天` | 只看昨天 |
| `/用量 周` | 按周看（近 8 周） |
| `/用量 月` | 按月看 |
| `/用量 全部` | 从记账那天起的全部 |
| `/用量 模型` | 哪个模型最费 |
| `/用量 群` | 哪个群最费 |
| `/用量 清空 [范围]` | 清账（**只有管理员能用**），范围可写 `今天`/`本周`/`本月`/`全部`，不写就是全清 |
| `/用量 帮助` | 完整说明 |

`/token` 是 `/用量` 的别名，两个都能用。

## 四、配置项

面板「插件管理 → TokenLedger → 配置」里改：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `auto_record` | 开 | 自动记账。关掉就彻底不记了 |
| `estimate_when_missing` | 开 | 接口不报用量时，按字数估一个数，并标「估算」 |
| `keep_days` | 90 | 账本留多少天，超期的按天文件自动删掉 |
| `track_users` | 开 | 记下说话人的昵称（关掉就只按群/模型统计） |
| `max_records` | 200 | 面板流水表最多显示多少行 |
| `time_zone` | `UTC+8` | 账本上的时间和「今天 / 本周」的日界按哪个时区算 |
| `view_key` | 空 | 填了就要求网页地址带 `?key=同款值` 才能取数 |

### 时区

服务器大多跑在 UTC 上，人在东八区——那就差 8 小时，最直接的后果是**早上 8 点前的对话会被算进前一天**，面板上「今天」那格看着就不对。

`time_zone` 默认 `UTC+8`（北京时间），也就是说装完就对了。可以填：

| 填法 | 意思 |
| --- | --- |
| `UTC+8` / `+8` / `Asia/Shanghai` / `beijing` | 东八区，都是同一个意思 |
| `UTC` | 零时区 |
| `UTC-5` / `-5` | 往西偏 5 小时，-12 到 +14 之间的整数都认 |
| `local` / 留空 | 跟服务器系统时区走（以前的老行为） |

改完重启插件（或者重载）生效。它管三件事：流水表里那列时间、按天切文件用的日期、「今天 / 本周 / 本月」的零点。

### 群聊和私聊

流水表第二列就是场景：蓝标签「群」是群里说的，紫标签「私」是私聊说的，看不出来显示「—」，不乱猜。

不用额外配置，能认的都认了：`GroupMessage` / `FriendMessage` 这类来源字符串、平台给的 `is_private_chat()`、`get_group_id()`、以及消息对象上的类型字段。挨个试，试不出就留空。

「谁最费」那块也能按场景排——点「场景」，就变成「群聊一共花了多少、私聊花了多少」。

## 五、它是怎么知道用量的

AstrBot 每次模型回复完会发一个 `OnLLMResponse` 事件，回复对象上带着 `usage`：

```
TokenUsage
  input_other    正常输入（不含缓存）
  input_cached   缓存命中的输入
  output         输出
```

插件挂在这个事件上，只读这三个数。**不拦消息、不改回复、不存聊天内容**，只是把数字记下来。

几个实际会遇到的情况，都已经处理好了：

- **流式回复**：一次回复会来好几趟，前几趟只有碎片、没有用量。插件只在带用量的那一趟记账，碎片一律不估（否则一条回复能冒出好几笔假账）。
- **全零用量**：流式前缀有时会带个全零的 usage，这个不是真数据，跳过。
- **模型名**：回复对象身上其实没有 `model` 字段，模型名藏在 `raw_completion.model` 里，有些中转接口连这个都不给。插件额外挂了请求阶段的钩子，先把模型名存一份，回复那一步取不到时拿来补。
- **接口不报用量**：按字数粗估（中文约 1 字 0.75 token 一刀切），账本上给这笔打个 `*`，一眼能看出哪些是猜的。
- **记账出错**：所有异常都吞掉，只写日志。记账永远不该弄坏聊天。

## 六、数据存在哪

优先存在 AstrBot 官方的插件数据目录：

```
AstrBot/data/plugin_data/astrbot_plugin_token_meter/2026-11-05.jsonl
```

一天一个文件，一行一笔账。为什么不用数据库：账本只是流水，读写都是顺序的，几万行也就几 MB；删旧账直接删文件，不用 VACUUM 也不怕锁表。

每行长这样：

```json
{"t":1762318000.123,"d":"2026-11-05","io":1200,"ic":8000,"o":350,
 "s":"aiocqhttp:GroupMessage:123456","m":"deepseek-chat","u":"10086","un":"小明"}
```

| 键 | 意思 |
| --- | --- |
| `t` | 时间戳 |
| `d` | 哪天（也是文件名） |
| `io` / `ic` / `o` | 正常输入 / 缓存命中 / 输出 |
| `e` | 有 1 表示这笔是按字数**估**的 |
| `s` | 会话（群号 / 私聊） |
| `m` | 模型名 |
| `c` | 场景：`群` 还是 `私`，认不出就没有这个键 |
| `k` | 1 = 它先开口，0 = 人找它 |
| `u` / `un` | 用户号 / 昵称 |

想搬账本、想备份、想拿去做别的统计，直接拷这个目录就行。

### 手动清理

两个口子，都能按范围删：

**面板里**：视图右上角「清理数据」按钮。点开以后选一段——今天 / 本周 / 本月 / 全部。**要连点两下**：第一下只是选中，第二下才真删。这是故意的，免得手滑。

**群里**：`/用量 清空 今天`，范围可以写 `今天` / `本周` / `本月` / `全部`，不写就是全清。只有管理员能用。

删的范围是按**日期文件**整个删的，不是逐行重写，所以很快。删掉就是删掉，没有回收站。

## 七、常见问题

**面板里找不到「扩展功能」里的视图？**
这个 AstrBot 版本可能没有 `register_web_api`，视图挂不上——但指令 `/用量` 照样能用，账也照样在记。

**账本一直是空的？**
按顺序看两件事：
1. 配置里 `auto_record` 是不是被关了；
2. 插件数据目录里有没有 `YYYY-MM-DD.jsonl` 文件。

**数字比面板上显示的多/少？**
账本数的是**模型接口真实回报的用量**。如果模型走了自带工具调用的多轮，每一轮都会各记一笔——这是对的，那确实是多次调用。

**缓存命中数是 0？**
说明这个模型接口没启用 prompt caching，或者没回报这个字段。不是插件的问题。

**只想看群的整体消耗，不想记昵称？**
配置里 `track_users` 关掉，账本上就不会有 `u`/`un` 两个字段了。

## 八、版本

**v1.1.1**
- 数字写法：一万以下直接写四位数（`2400`，不再是 `2.4千`），一万以上用「万」，一亿以上用「亿」。「千」这个单位整个去掉了
- 卡片、柱状图的鼠标提示、`/用量` 的回复，三处统一

**v1.1.0**
- 时区：新增 `time_zone` 配置，默认 `UTC+8`。流水时间、按天切文件的日期、「今天 / 本周」的零点全按它算——服务器在 UTC 上跑也不会再把早上 8 点前的账算到前一天
- 场景：流水表新增第二列，蓝标签「群」/ 紫标签「私」，认不出来显示「—」；「谁最费」多了「场景」这个口径
- 脚注会写明当前按哪个时区算，`/health` 里也能看到时区名和当前时间

**v1.0.0**
- 记账：每次模型回复的输入 / 缓存命中 / 输出，分模型、分群、分人
- 统计：今天、本周、本月、全部，各带环比；近 14 天、近 8 周
- 视图：面板「扩展功能」里的账本页（四张卡 + 柱状图 + 排行 + 逐条流水表）
- 发起：流水表标出「它」（机器人自己先开口）和「你」（人来找它），四张卡标题写它主动的次数
- 清理：视图右上角「清理数据」，今天 / 本周 / 本月 / 全部，连点两下才删；也可以 `/用量 清空 本周`
- 指令：`/用量` 九种问法
